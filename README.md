## 📌 Project Overview

Amazon Product Analysis is an Exploratory Data Analysis (EDA) project that analyzes an Amazon products dataset to discover meaningful insights related to product pricing, discounts, customer ratings, review counts, and product categories.

The project follows a complete data analysis workflow, including data cleaning, preprocessing, feature engineering, statistical analysis, visualization, and business insight generation.

---

## 🎯 Objectives

- Perform complete Exploratory Data Analysis (EDA)
- Clean and preprocess real-world e-commerce data
- Handle missing values and duplicate records
- Convert incorrect data types
- Detect and analyze outliers
- Create new features using feature engineering
- Perform univariate, bivariate, and multivariate analysis
- Generate actionable business insights through visualization
